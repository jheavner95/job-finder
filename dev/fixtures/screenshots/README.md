# Screenshot placeholders

Privacy-safe product screenshots may be added here after the application has
been populated exclusively with synthetic demonstration data.

Planned filenames:

- `dashboard.png`
- `daily-briefing.png`
- `job-finder.png`
- `review-queue.png`
- `career-evidence.png`
- `onboarding.png`

Do not add screenshots that show names, resumes, portfolio content, company
preferences, imported jobs, local paths, or other personal information.
